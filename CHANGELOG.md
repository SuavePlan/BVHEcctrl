# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Enterprise-grade testing infrastructure with Vitest
- Biome for linting and formatting
- Comprehensive TypeScript strict mode configuration
- Bundle size tracking and optimization
- Security and contributing documentation
- Automated changelog management
- CI/CD workflows

## [0.0.18] - 2025-01-XX

### Added
- Counter acceleration factor support
- Joystick component for mobile controls
- VirtualButton component for touch controls
- Animation store for character animation state
- Button store for virtual button state
- Joystick store for joystick state

### Changed
- Refactored BVHEcctrl with improved physics calculations
- Updated collision detection algorithm
- Enhanced platform movement support

### Fixed
- BVH helper debug improvements
- Collision response edge cases

## [0.0.17] - 2024-XX-XX

### Changed
- Updated BVH helper debug functionality
